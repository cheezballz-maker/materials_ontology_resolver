# Publication contents

This repository contains the resolver source, tests, contracts, reports, operational association schemas and bundled OPSIN source. Third-party OPSIN licensing remains in its source directories. No project-wide license is assigned by this publication.

API keys, local environment files, registry/candidate databases, source workbooks, provider response caches, generated evaluation outputs and build binaries stay outside Git. Reports describe the original local experiments; some contain historical absolute paths and refer to local assets that are not distributed here. Frozen integrity manifests refer to that original workspace, rather than this source-only checkout. Full historical replay needs those original assets and paths; it is not claimed to work from a fresh checkout alone.

Stage C source and reports include the v5 stereochemical qualification experiment. Its monitored expansion stopped after phase 2 when review quarantined a Benzylhemiformal mapping and alias. The Stage C warehouse snapshots, provider receipts and fixture databases are local prerequisites for integration tests and replay. [Stage C v5 report](canonical_registry/STAGE_C_V5_EVIDENCE_COVERAGE_AND_MONITORED_EXPANSION_REPORT.md).

The authoritative ontology and molecular identity framework are copied into `ontology/`; originals were not modified. Existing code retains its established configuration/path assumptions. Configure local source data and tool paths before full processing.
