# Exact-form evidence increment — development re-evaluation

The existing 360-case set has informed development. This is not a fresh independent holdout. All original source packets, frozen references, previous predictions and registries remain immutable. No reference name/structure lookup file is used by the resolver. Existing reviewed contradiction evidence is retained unchanged; no new case-specific knowledge is added.

Preserve chemistry.py, form_characterizer.py, identity_comparator.py, policy.py, ID allocation, schema and ontology semantics. New acquisition can use complete validated structures/identifiers, exact source claims and independently validated original aliases. It must retain all original-claim contradictions. Discovery-only related forms are diagnostics, not corroboration. External-only independence is not inferred from provider count or unknown aggregate lineage. An original source alias can supply local parser support only after warning-free parsing, exact graph comparison and its own external exact-name validation; it cannot fill missing preferred-referent stereo, isotope or form specification.

Run all old tests and new retrieval tests before the development run. Freeze runtime hashes before reading upgraded outcomes. Use one new 360-case snapshot, copied baseline name-query caches to control repeated evidence, and separate new caches. Maximum new HTTP requests: PubChem 1,800; ChEBI 3,000; GSRS 500. Per referent: 16 query operations; at most three structurally matching original alias claims receive recovery lookups. No full CUMA run. No retry/cache deletion or label revision to improve evaluation results.

Score with the unchanged frozen-holdout graph equivalence and metric definitions (import functions, never execute its old main or overwrite its outputs). Report adjudicable precision and unverified admissions separately; unresolved references are not automatically errors. Report before/after counts, precision, recall, false merges and their denominator, abstention, alias precision, new/revoked admissions and newly exposed conflicts. Attribute recoveries to actual query/support traces, not presumed benefits.

Audit every newly admitted record against source intent, unchanged form/comparison gates, official InChI, returned evidence and original graph(s). Report form categories, dimensions, provider/query provenance and frozen reference judgment. Do not silently revise an unverified reference. New unverified admissions are not confirmed recoveries. Hash-check protected files, labels and original databases; run the existing verifier extended only to replay acquisition evidence/provenance.

Any runtime defect discovered during evaluation must be disclosed with the failed attempt retained; do not tune behavior against labels. This protocol does not promise a coverage gain. Secondary semantics, salt proton transfer, advanced stereo, coordination, hydrate/solvate modeling, and ontology changes remain outside this increment.
