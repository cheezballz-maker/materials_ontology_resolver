# Methodological notes

- Sampling eligibility and exclusions were computed before any seeded random draw. The full eligible-ID and exclusion files were serialized together with the final sample freeze, rather than as a separately timestamped artifact before the first draw. The saved sampling script, source hash and seed reproduce this order. All were frozen before adjudicator dispatch; no predicted outcomes were consulted.
- A source-only preview exposed an empty narrow solvate-name pool. Before freezing or adjudicating, the solvent-associated candidate pattern was broadened to include explicit solvent/ratio descriptions. These are coverage candidates, not established solvates; alkoxides and other compounds must not be relabelled as solvates to fill quotas.
- Lexical pair masks can collect whitespace/case duplicates or other constitutional relationships. In particular, a label such as `pair_isotope` or `pair_solvate` does not establish an isotope or solvate relationship. Report independent reference relations and unassessable pairs explicitly.
- Fresh agents received no project conversation and were instructed to access only their assigned source packets/framework. Filesystem isolation is procedural, not an OS access restriction. Predictions are gated on all frozen reference packets.
- Blinding prevents prediction leakage, but shared public databases and name-parsing algorithms create methodological dependence. They are not independent experimental observations. Record primary-source investigations, copied upstream lineages, parser dependence, transport errors and unresolved evidence separately.
- Before prediction, a scorer limitation was identified: the inherited strict RDKit resonance enumeration does not equate hypervalent `CS(=O)[O-]` and charge-separated `C[S+]([O-])[O-]`, despite their shared Standard InChIKey. Key equality alone must still not force identity. Resolver, scorer and reference labels remain unchanged. Any affected predicted/reference disagreement must be identified explicitly as a representation-review issue rather than silently treated as a demonstrated chemical error; report whether any scored result is actually affected.
