# CUMA blinded validation report

**Conclusion: NOT_READY_TO_SCALE.**

The frozen review corroborates 58/114 automatic admissions and 56/196 promoted alias occurrences. One admission retains a source-level tautomer conflict; the remaining uncertainty and only 2 testable merge pairs prevent a reliable scale-up claim.

## Design and blinding

300 original CUMA records were sampled with seed 20261027. Sampling includes the full existing automatic-admission cohort, all existing provider-conflict records, and randomly selected challenge strata; overlapping traits are assigned one primary sampling stratum. The sampling steward used engine categories to assemble strata but did not assign reference judgments. Three fresh adjudicator agents received shuffled original indices, preferred names and aliases only. They received no earlier chat history, engine outputs or stratum labels. This is procedural blinding on a shared filesystem, not OS-enforced isolation or independent human expert review. The parent had prior exposure to some results and did not assign reference labels.

Every packet was frozen with a SHA256 before the comparison program opened predictions. Frozen files were verified unchanged, as were both source databases. The canonicalization pipeline and registry were not altered. Reference labels were not revised after unblinding. The [protocol](blinded_validation/PROTOCOL.md), [300-record reference index](blinded_validation/reference_index.json), and [full comparison](blinded_validation/comparison.json) accompany this report. The reference index includes exact structures, full InChIKeys and corroborated SAME aliases; original aliases, alternate-form diagnostics and complete evidence remain in the three frozen packets.

The reference judgment asks what molecular identity is independently supported, not whether the engine had query budget available. Expected EXACT versus engine UNRESOLVED can therefore represent intentional conservative abstention. Challenge strata are lexical/candidate screens, not ground-truth classifications (a chloride name need not denote an ionic salt). This enriched sample does not estimate whole-CUMA coverage or outcome prevalence.

The one false-positive EXACT classification is CUMA 5, **5-Amino-3H-1,2,4-dithiazole-3-thione**. The engine, PubChem and Fisher support amino-thione `Nc1nc(=S)ss1`; the frozen review found a Wiley SpectraBase record under the same name represented as imino-thiol `N=c1nc(S)ss1`. Both regenerate Standard InChIKey `YWZHEXZIISFIDA-UHFFFAOYSA-N`. This is a missed conflicting-evidence finding under the strict tautomer policy, **not proof that the admitted amino-thione graph is wrong**. Human review should inspect the source assignment before treating it as a confirmed chemical misidentification. [Fisher](https://www.fishersci.nl/nl/en/browse/cas/6846-35-1), [Wiley SpectraBase](https://spectrabase.com/spectrum/LHSxszxMwZO).

Of the 128 record disagreements, 55 are unverified engine admissions and 53 are independently supported identities on which the engine abstained. Low status agreement therefore combines reference uncertainty, conservative engine scope/budget decisions, and substantive evidence differences; it is not the automatic identity-error rate.
