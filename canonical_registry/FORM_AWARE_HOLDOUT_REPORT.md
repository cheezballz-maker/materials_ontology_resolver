## Scope and leakage controls

360 CUMA records, seed `2026102702`, source workbook SHA-256 `80c87da79fe54c70865cdaae0dba85252907351b3e62304d49253f45117200f3`. The sample was frozen at 2026-10-27 16:26:49 SGT; all references were frozen before resolver execution. The cohort is deliberately enriched for capability boundaries and is not representative of whole-CUMA prevalence.

Selection used original names/aliases only, with no resolver outcome or parser-result filtering. It excluded the prior 300 indices, known development examples and conservative name/alias overlaps: 1,545 source records in total. Known development leakage was checked by index and lexical overlap; undocumented historical exposure or unrecognized chemical synonyms cannot be ruled out. Source workbook, sample, selection procedure and protected implementation artifacts were hashed.

Three fresh agents with no inherited chat history independently investigated 120 shuffled records each. They received only their original input packet and the authoritative identity framework, with no sampling stratum, previous results, resolver diagnostics or predictions. Access isolation was procedural on a shared filesystem, not an OS sandbox. No holdout predictions were generated until all three references had been hashed and structurally validated. A pre-unblinding clarification kept primary identity and misleading-alias judgments separate.

References use independent external investigation and bare RDKit validation; no project resolver/provider logic was imported for adjudication. EXACT requires corroboration beyond a single database hit. Source dependence and uncertainty remain explicit. The independent graph scorer preserves stereo, isotopes, charge, hydrogen/bond placement and components; Standard InChIKey alone cannot establish exactness. No label was changed after unblinding.

**Primary recommendation: exact-form evidence retrieval and corroboration coverage.** This is the largest directly observed bounded evidence bottleneck: 32 distinct reference EXACT identities were lost across ordinary molecules, stereochemical forms, salts, hydrates, isotopes and both confirmed solvates. Of these 32, PubChem returned structures for 18 and no name result (HTTP 404) for 14; ChEBI supplied no qualifying corroborating row for any (22 HTTP 404 responses, 10 searches with zero qualifying rows). Sixteen of those 18 PubChem candidate sets contained a reference-equivalent graph; the other two illustrate why a single-hit relaxation would be unsafe (4023: missing stereo; 10218: incorrect lithium charge). Budgets were not exhausted. A bounded increment should acquire and validate exact-form evidence with explicit source provenance when local parsing or name lookup fails, without lowering the admission threshold, treating copied data as independent, or automatically selecting parents. The 32 losses are an opportunity set, not a promised gain. Neutral-base-plus-acid semantics remains secondary: the component-gated set also contains already charged quaternary ammonium/phosphonium salts and unsupported inorganic chemistry, so a blanket proton-transfer rule would neither address the main evidence gap nor be safe.

## Execution integrity and limitations

The unchanged resolver processed exactly 360 frozen inputs once, with fresh engine HTTP caches and fixed caps of 1,800 PubChem / 3,000 ChEBI requests. Actual requests: 340 PubChem, 349 ChEBI. Reference caches were not copied into engine evidence. The evaluation registry contains 89 identities; it is isolated from the production registry. No resolver/admission/provider code, test, ontology, schema, previous reference or existing registry was changed.

The existing verify.py returned PASS: all 90 EXACT reconciliations and 89 canonical graphs were revalidated against stored evidence. SQLite integrity and foreign keys passed; duplicate IDs, duplicate alias/identifier/reconciliation assertions and orphan alias/identifier/structure/reconciliation rows were all zero. The scorer also confirmed all 40 protected implementation/reference/registry files unchanged. These are internal consistency checks, not an independent chemical truth guarantee.

Conditional precision is 100% on 74 adjudicable admissions, but only 74/90 (82.22%) of all admissions are independently confirmed. An illustrative Wilson 95% interval is 95.07–100% for EXACT precision and 86.20–100% for the 24 assessable alias promotions; these are not population confidence guarantees for a stratified, correlated, agent-reviewed sample. Only 24/114 promoted alias occurrences were assessable. Across all 1,667 original alias occurrences, references label 71 SAME, 192 DIFFERENT and 1,404 UNKNOWN; 1,553 were not promoted. The sole assessable merge pair is duplicate dodecane records 21397/51379, so 0/1 false merges provides almost no evidence about difficult near-duplicate merging.

All 16 unverified admissions retain their frozen UNRESOLVED references. Priority review cases are phenylglyoxal monohydrate 29854 (dot-water versus covalent gem-diol), calcium methoxide 15411 and potassium perfluorobutanesulfonate 11065 (ionic versus metal-bonded depictions), sodium di(isobutyl)dithiophosphinate 33551 (charge specification), 2H heterocycle 42231 (fixed tautomer), and 40438 (absolute stereo versus broader catalog records). These are unresolved safety questions, not established false positives or confirmed correct admissions.

Adjudicators produced 74, 39 and 54 EXACT labels respectively; their 120-record packets differ in case mix and evidence availability. No duplicate cross-adjudication or expert consensus panel was performed. In particular, some explicitly fixed salt compositions were accepted with neutral base-plus-acid source depictions while another adjudicator withheld cases lacking ionic/proton-site corroboration. This variability limits comparability and is documented rather than corrected after unblinding. Several composition-level inorganic reference identities exceed the current engine scope; the metric term “excessive abstention” denotes reference EXACT losses, not proof that every gate should be relaxed. Four UNRESOLVED references whose basis is CONFLICTING_EVIDENCE remain unassessed under the prespecified rubric; all four were withheld. No unit or integration tests were changed or rerun in this evaluation; the existing registry/evidence verifier was run on the new snapshot.

The benchmark is a capability-enriched, agent-adjudicated holdout, not independent expert certification or an estimate of whole-CUMA prevalence. Shared underlying reference databases and shared graph tooling can correlate errors. Sparse positive cases limit form-specific conclusions. No tuning, retries designed to change outcomes, or development extension was performed during this task.
